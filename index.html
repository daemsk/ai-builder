Design System Skill · How I Built This

From inspiration to reusable skill

1
Found an inspiration website

Spotted Noom's site and liked the editorial warmth: serif headlines, nature greens, generous space. That was the aesthetic I wanted to carry across all my builds.

2
Used Claude in Chrome to extract the design DNA

Pointed Claude at the live site and asked it to identify every color, typeface, spacing pattern, and layout principle it could find. One prompt, full system extracted.

3
Used /skill-creator to turn it into a reusable skill

Pasted the extracted design tokens and principles into a structured SKILL.md using the skill creator. It became a self-contained instruction set Claude reads before any build.

/skill-creator
4
Now it works everywhere

Type /noom-design at the start of any session and every build, whether a website, doc, or deck, automatically matches the style. No re-explaining the design system.

Layout Principles
  • Full-bleed editorial sections: each section has a distinct background color
  • Max content width of 1100px, centered with generous side padding (48px)
  • Vertical section padding: 80 to 120px so sections breathe and never feel cramped
  • 3-column feature grids with rounded card corners (16 to 20px radius)
  • Sticky transparent nav that picks up a white blur on scroll
  • Pill-shaped buttons only: border-radius 50px on all CTAs
  • Serif headlines set tight (line-height 1.0), sans body set relaxed (1.7)
  • Decorative blobs and dot grids for hero depth: never in content areas

Portfolio Website · How I Built This

How this site got built

1
Started with a scaffolded HTML page

Asked Claude to build a complete portfolio structure in a single HTML file: hero, about, work, projects, contact. The first version was a dark minimal design with all sections stubbed out.

2
Applied my design system skill to style it

Typed /noom-design at the start of the next session and asked Claude to restyle the whole page. The skill loaded the full color palette, typography specs, and layout rules and applied them in one pass.

3
Claude interviewed me to fill in real content

Instead of writing everything from scratch, Claude asked about my title, work focus areas, About section tone, and contact info. The answers became the actual copy.

4
Built out project cards as I completed each session

Each AI Builder session produced a new project. As I finished them, I came back and asked Claude to fill in the card: description, popup content, and badge, turning "Coming Soon" into "Live" one at a time.

Portfolio Website · Documentation

Build your own portfolio with AI

Techniques used

  • Single-file HTML — everything in one .html file: styles, scripts, markup, modal content. No build step, no dependencies beyond Google Fonts.
  • Design skill injection — invoke /noom-design (or your own skill) at session start so Claude applies your brand system without any re-explanation.
  • CSS custom properties — all design tokens stored as :root variables so the entire palette and typography can be swapped in one block.
  • Inline modal system — popups are hidden divs toggled by JavaScript. No libraries needed, keeping the file truly self-contained.
  • Iterative card filling — project cards start as "Coming Soon" stubs. Each new project session adds real content to one card, keeping momentum without needing the full site done upfront.
  • Claude as interviewer — rather than writing copy from scratch, let Claude ask questions and turn your answers into finished prose.

Key prompts for your own build

  • Scaffold: "Build me a simple portfolio website as a single HTML page. Interview me about any info you don't have. Google Fonts are the only allowed external resource."
  • Style it: "/noom-design — apply this to my portfolio HTML file. Keep all content, just restyle everything."
  • Fill content: "Interview me about my title, work focus areas, and About section tone. Use my answers to write the actual copy."
  • Add a card: "Fill in the [Project Name] card in my portfolio. Here's what it does: [description]. Write the How I Built This popup as a step-by-step."
  • Update a badge: "Change the [Project Name] card badge from 'Coming Soon' to 'Live'."
